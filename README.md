 # Projeto de CRUD com Sistema de Sacola de Compras
## Descrição
Este projeto é um sistema simples de CRUD (Create, Read, Update, Delete) para manipulação de um array que simula uma sacola de compras. A interação com o usuário é feita através de caixas de diálogo alert, prompt e confirm do JavaScript. O projeto permite adicionar, visualizar, editar e remover itens da sacola de compras.

## Funcionalidades
### Adicionar Item: 
O usuário pode adicionar um item à sacola de compras especificando o nome do produto e a quantidade.
Listar Itens: O sistema exibe todos os itens atualmente na sacola de compras.

### Editar Item: 
O usuário pode modificar a quantidade de um item existente na sacola.

### Remover Item: 
Permite remover um item específico da sacola.
Esvaziar Sacola: O usuário pode optar por remover todos os itens da sacola.

### Listar Item:
Permite o usuario ver todos os produtos adicionados a sacola

## Tecnologias Utilizadas
### HTML5: 
Para estruturar a página web.
### JavaScript: 
Para a lógica de manipulação dos dados da sacola de compras.

## Como Usar

Clone este repositório em sua máquina local.

Abra o arquivo index.html em seu navegador web.

Utilize as funções disponíveis, que são disparadas por botões na interface ou automaticamente ao carregar a página:

### Adicionar Item: 
Um prompt será exibido para que você insira o nome do item e a quantidade.

### Listar Itens: 
Um alert mostrará todos os itens atualmente na sacola.

### Editar Item: 
Um prompt solicitará o nome do item que você deseja editar e, em seguida, a 
nova quantidade.

### Remover Item: 
Um prompt solicitará o nome do item que você deseja remover.
Esvaziar Sacola: Exibe uma confirmação antes de limpar todos os itens da sacola.

## Estrutura do Projeto
### index.html: 
Estrutura básica da página HTML.
### script.js: 
Contém a lógica JavaScript para manipulação do array da sacola de compras.
